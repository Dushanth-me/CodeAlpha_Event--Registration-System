# Event Registration System

A web-based Event Registration System developed as part of the CodeAlpha Internship.

## Project Description

The Event Registration System is a web application that allows users to view event information and register for events through an easy-to-use interface.

The system is designed to simplify the event registration process and manage participant information efficiently.

## Features

- User-friendly event registration interface
- Event details and information
- Participant registration
- Form validation
- Responsive web interface
- Backend developed using Flask
- HTML and CSS based frontend

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- SQLite
- Git
- GitHub
